# Telegram_MassMess

Designed and implemented an automated messaging engine in n8n connecting an admin-facing Telegram bot to a PostgreSQL subscriber database. The solution enables authorized administrators to broadcast instant or scheduled announcements to all active users with custom delivery timing and permission validation.

Prerequisites:

Telegram Bot API Token + PostgreSQL Database Credentials
